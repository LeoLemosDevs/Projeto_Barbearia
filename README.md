# Barbearia — Sistema de Gerenciamento

Sistema web responsivo para gestão de barbearia: cadastro de clientes, barbeiros e cabeleireiros, agenda de horários, caixa diário e controle financeiro mensal.

## Stack

- **Frontend:** HTML5, CSS3, JavaScript (SPA)
- **Backend:** PHP 8 (API REST)
- **Banco de dados:** MySQL / MariaDB (XAMPP)

## Como executar

1. Copie o projeto para `C:\xampp\htdocs\barbearia`.
2. Inicie o Apache e o MySQL no XAMPP.
3. Acesse `http://localhost/barbearia/database/seed.php` para criar e popular o banco.
4. Acesse `http://localhost/barbearia/` e entre com:
   - **E-mail:** `admin@barbearia.com`
   - **Senha:** `123456`
